# 🏥 MediCare – Hospital Appointment & Management System

> **Web Technology Final Project**  
> *Developed by Faraz Hussain & Shahzaib Raza*

MediCare is a modern, responsive, and fully dynamic single-page web application designed for streamlined hospital management, doctor lookup, and real-time patient appointment booking. Built using core Web Technologies (**HTML5, CSS3, and modern JavaScript**), it provides an intuitive administrative UI.

---

## ✨ Key Features

- **📊 Dynamic Dashboard Overview:** Instant summary cards displaying total appointments, available doctors, active patients, and medical report statuses.
- **👨‍⚕️ Specialist Doctors Catalog:** Searchable directory with real-time text-filtering by doctor name or medical specialization.
- **📅 Interactive Booking Engine:** Modal-based appointment booking system that dynamically updates table records and counter metrics.
- **📋 Live Status Tracking:** Track appointment status (`Confirmed` vs `Pending`) with dynamic record deletion and updates.
- **⚙️ Profile & System Settings:** Real-time patient/admin profile updates directly reflecting across the top navigation bar.
- **📱 Fully Responsive Design:** Modern CSS Variables theme tailored with healthcare palette (Teal & Emerald hues).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and form elements.
- **CSS3:** Custom UI design using Flexbox, CSS Grid, and CSS Variables.
- **JavaScript (ES6):** Dynamic DOM manipulation, modal popups, tab routing, and real-time array filtering.
- **FontAwesome v6:** High-quality medical and UI icons.
